## 来源与整理

各题在本地练习源文件中的行号、源文件 SHA-256 和题目链接见 [索引](牛客/索引.json)。`tempCodeRunnerFile.cpp` 是临时运行副本，不重复收录。

- 题目分类和名称均按上述题单核对，包括 `[NOIP年份]` 前缀和题名中的标点。
- 移除程序外层的块注释和 `#include` 后的题目文字，保留算法及输出内容。
- “随机序列”在循环结构源文件中也出现一次，合并收录并保留两个来源。
- “日历中的数字”原注释块有两个 `main`，拆分版仅保留后一个日历程序；无输出的残留草稿未单独收录。
- “233”补充 `<string>` 头文件，其余算法和判断条件按原稿保留。
